Bitácora del proyecto

En esta sección registramos el proceso de desarrollo del Trabajo Práctico 1, las decisiones tomadas por el equipo, las dificultades encontradas y los cambios realizados durante la construcción del sitio web.

Inicio del proyecto

Fecha: Agosto de 2026

¿Qué hicimos?

Creamos el repositorio del proyecto y establecimos la estructura inicial de carpetas y archivos.

Decisiones tomadas

  • Utilizar HTML, CSS y JavaScript.
  • Separar los archivos HTML, CSS y JavaScript.
  • Utilizar una carpeta img para las imágenes.
  • Utilizar Google Fonts para la tipografía.
  • Trabajar mediante ramas de Git para evitar modificar directamente la rama principal.

Dificultades

Uno de los primeros desafíos fue organizar el repositorio y establecer una forma de trabajo colaborativa que permitiera que cada integrante desarrollara su parte sin sobrescribir el trabajo de los demás.

Desarrollo del perfil individual

Fecha: Agosto de 2026

¿Qué hicimos?

Cada integrante comenzó el desarrollo de su perfil individual dentro del proyecto. Para trabajar de manera independiente, creamos las ramas feature/perfil-[nombre] y agregamos nuestros avatares en la carpeta destinada a las imágenes.

Luego desarrollamos el archivo correspondiente a cada perfil, incorporando los datos personales, habilidades, películas favoritas y discos favoritos, siguiendo los requisitos de la consigna.

Decisiones tomadas

  • Trabajar el perfil individual en una rama propia.
  • Utilizar el archivo js/script.js para las funciones dinámicas.
  • Utilizar el avatar almacenado dentro de la carpeta img.

Dificultades

Fue necesario familiarizarse con el flujo de trabajo mediante ramas en Git y GitHub Desktop, especialmente para mantener los cambios separados de la rama principal y poder incorporarlos posteriormente mediante un Pull Request.

Incorporación de función dinámica al perfil

Fecha: Septiembre de 2026

¿Qué hicimos?

Incorporé una función dinámica mediante JavaScript en mi perfil individual. Se agregó un botón de saludo que muestra un mensaje personalizado al ser presionado.

Decisiones tomadas

  • Utilizar un botón para activar la función dinámica.
  • Mantener la función JavaScript en el archivo js/script.js.
  • Mostrar el resultado directamente dentro de la página.

Dificultades

Fue necesario comprobar la comunicación entre el HTML y el archivo JavaScript externo y verificar que la función se ejecutara correctamente al presionar el botón.
